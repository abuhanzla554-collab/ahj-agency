AHJ DIGITAL — WEBSITE PACKAGE

Files: index.html (Home), about.html, services.html, pricing.html, team.html, portfolio.html, contact.html.
Shared assets: assets/style.css, assets/script.js, owner.jpg and four locally created SVG concept visuals.

HOW TO OPEN
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.

BEFORE PUBLISHING
- Confirm the domain ahjdigital.com and update canonical URLs + sitemap.xml if your real domain differs.
- Confirm WhatsApp number and email.
- Replace concept portfolio artwork with actual approved client work when available.
- Verify all factual claims (years of experience, clients, results) before publishing. This package only uses 50+ projects completed because the owner stated that figure.
- SEO setup is a foundation, not a guarantee of first-place Google rankings. Backlinks are not fabricated or auto-created; earn real links from relevant directories, partners and publications.
- The contact form opens WhatsApp; it does not store leads on a server.
